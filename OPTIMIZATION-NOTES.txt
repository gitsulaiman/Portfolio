Security notes
- This is a static front-end portfolio. It does not contain a server-side contact endpoint.
- The contact form uses the visitor's email application via mailto; it does not securely transmit/store messages itself.
- Do not place API keys, passwords, database credentials, private tokens or .env secrets in this public repository.
- GitHub Pages does not provide per-site HTTP security headers from these files. Configure headers at a hosting/CDN layer if you move to a host that supports them.
- External libraries still load from their public CDNs. Review/update dependencies periodically; use pinned versions and Subresource Integrity where supported.
- SEO metadata and sitemap improve crawlability but do not guarantee indexing or rankings.
